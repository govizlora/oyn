<h2 id="installation">Installation</h2>

With the OYN registry running locally and the OYN workspace packages available in your React 19 project, add Button with shadcn.

<InstallCommand item="button" />

## Usage

Wrap your app in an `OynProvider` once. With the default shadcn UI alias:

```tsx
import { OynProvider } from "@oyn/react";
import { Button } from "@/components/ui/oyn/button";

export function App() {
  return (
    <OynProvider>
      <Button>Continue</Button>
    </OynProvider>
  );
}
```
