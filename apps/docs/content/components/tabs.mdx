## Installation

With the local OYN registry running and the OYN workspace packages available, add Tabs with shadcn.

<InstallCommand item="tabs" />

## Usage

Under an `OynProvider`, give each `TabsTab` and its `TabsPanel` the same value. Use `TabsPanels` around the panels for a shared Ceramic surface. Use the arrow keys to move between tabs.
