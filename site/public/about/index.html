OYN

A UI you can feel.

OYN is a material system for native HTML, with materials rendered by the GPU. Its ceramic controls show depth through light and shadow rather than a new background color or border for every state.

A button stays a button. The browser lays it out, gives it focus, and handles activation. The GPU paints its surface: a raised edge catches the light; a recessed track holds a shadow. Text and hit targets remain in the DOM.

How it works

Surface
Binds a GPU surface to a DOM element. HTML and CSS still own layout.
Ceramic
Turns geometry, elevation, and light into material highlights and shadows.
Interaction
Native HTML or the application owns selection, keyboard behavior, and motion. React is optional.

OYN is a work in progress. Try the Ceramic study, or explore the source on GitHub.
